# Phishing Email Analysis and Prevention

## Project Overview

This project demonstrates how to analyze a phishing email using common cybersecurity techniques.

## Objective

- Analyze a phishing email.
- Perform WHOIS lookup.
- Perform DNS analysis.
- Analyze the phishing URL.
- Check the URL using VirusTotal.
- Document findings and recommend preventive measures.
